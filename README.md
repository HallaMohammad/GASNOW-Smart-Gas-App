# GASNOW – Smart Gas Application Services in Jordan

## Overview
GASNOW is a mobile application designed to simplify gas cylinder ordering 
and delivery services in Jordan. The system connects customers, gas 
vendors, and administrators through a unified platform that supports 
order placement, real-time tracking, delivery scheduling, and vendor 
management.

## Features
- Customer registration and login
- Place, track, and cancel gas cylinder orders
- Vendor order management and delivery status updates
- Admin dashboard for managing users, prices, and complaints
- Rating and review system for delivery service
- Location-based tracking for delivery vendors

## System Design
The project was designed using object-oriented principles and modeled 
with UML class diagrams covering the following core classes:
- **User** (base class) → Customer, Admin, Vendor
- **Order** – handles order details, pricing, and status
- **Cylinder** – gas cylinder specifications and pricing
- **Location** – tracks delivery coordinates and addresses
